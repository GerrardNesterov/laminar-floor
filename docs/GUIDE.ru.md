# Первые шаги в LaminarFloor

[← О программе](../README.md)

## 1. Познакомьтесь с примером

В настольном приложении нажмите **«Учебный пример»**. Он помогает увидеть исходные параметры и профиль опоры. Используйте **«Генерировать»**, чтобы получить геометрию. Пример предназначен для знакомства с программой, а не для строительства готового пола.

## 2. Задайте параметры панели

Размеры вводятся в миллиметрах, нагрузка — в ньютонах, скорость воздуха — в метрах в секунду.

| Параметр | Значение |
|---|---|
| Ширина и глубина | Габариты отдельной панели |
| Номинальная толщина | Расстояние от рабочей плоскости до верха внешней опоры; посадка продолжается ниже этой отметки |
| Внешний бурт | Дополнительная радиальная ширина поверх обязательной стенки посадки; диапазон 0–10 мм |
| Материал | PETG, PP или PA6 |
| MMF и FoS | Раздельные параметры модели материала и запаса прочности; MMF задаётся в пределах 0,4–1,2 |
| Тип нагрузки | Человек, точечная, распределённая или оборудование |
| Печать | Сопло, ширина экструзии и высота слоя |
| Проходимость | Максимальный размер отверстия и минимальная доля контакта |

Значения по умолчанию не являются рекомендацией по допустимой нагрузке. После изменения параметров нужно повторно запустить генерацию.

## 3. Импортируйте опору

Нажмите **«Импорт DXF»** и выберите файл с замкнутым профилем опорного башмака. Программа интерпретирует профиль как тело вращения, а не как произвольную трёхмерную деталь.

Выберите верхнюю сторону профиля и положение оси — левый или правый край после ориентации выбранной стороны вверх. В окне профиля показаны выбранная сторона и ось. Если профиль не проходит проверку, исправьте исходный DXF.

## 4. Изучите результат

После генерации используйте переключатели **«Рабочая поверхность»**, **«Несущая структура»**, **«Посадки»** и **«Проблемы»**. Кнопка **«Перевернуть»** помогает рассмотреть нижнюю сторону.

Откройте **«Полный расчётный отчёт»**. Проверьте сообщения о геометрии, контакте, нагрузке, прогибе, открытости каналов и печати. Программа различает открытость рабочей поверхности и сквозную открытость с учётом опор.

## 5. Экспортируйте STL

Нажмите **«Экспорт STL»** и выберите место сохранения. Откройте полученный файл в слайсере и проверьте масштаб, целостность геометрии, ориентацию и траектории печати.

Расчётная ориентация: рабочая поверхность панели обращена к столу принтера. Экспорт может быть доступен при отрицательной оценке качества — сначала разберите причины в отчёте. Отсутствие геометрии и технические ошибки записи препятствуют сохранению.

## Горячие клавиши

| Команда | Клавиши |
|---|---|
| Сбросить параметры | Ctrl+N |
| Импорт DXF | Ctrl+I |
| Генерировать | F5 |
| Экспорт STL | Ctrl+E |

## Частые вопросы

**Можно сохранить проект и открыть позже?** В текущем интерфейсе v6 такой функции нет. Зафиксируйте параметры отдельно.

**Нужен интернет для расчёта?** Вычисления выполняются локально. Готовая сборка содержит необходимые компоненты.

**Можно применять панель как несущий пол?** Одного расчёта программы для такого решения недостаточно. Нужны проверка конструкции и испытания конкретной детали и материала.

**Где скачать приложение?** [Скачайте EXE со страницы релиза](https://github.com/GerrardNesterov/laminar-floor/releases/tag/v6-preview), сохраните в обычную папку и запустите. Python и Qt устанавливать не нужно.
